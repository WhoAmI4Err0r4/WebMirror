# WebMirror
🌐 A lightweight Termux website mirroring tool for authorized website backups, archiving, and offline inspection.

# 🌐 WebMirror v1.0.0

A lightweight website mirroring and archiving tool for Termux.

## ✨ Features

- 🌐 Mirror public websites
- 📄 Download individual HTML pages
- 🔗 Convert links for offline viewing
- 🖼️ Download page resources such as CSS, JavaScript, and images
- 📁 Choose a custom output directory
- ⚡ Simple Termux command-line interface
- 🔐 Designed for authorized website archiving and testing

## 📱 Installation

```bash
git clone https://github.com/WhoAmI4E/WebMirror.git
cd WebMirror
chmod +x webmirror_termux.sh
./webmirror_termux.sh
